# CodeAlpha Hangman Game

## Project Overview
A simple text-based Hangman game developed using Python as part of my CodeAlpha Python Programming Internship.

## Features
- Random word selection
- Letter-by-letter guessing
- Maximum of 6 incorrect guesses
- Input validation
- Win and lose conditions

## Technologies Used
- Python
- Random module
- Loops, lists, strings, and conditional statements

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the terminal in the project folder.
4. Run `python hangman.py`.
